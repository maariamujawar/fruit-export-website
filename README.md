# 🍎 Fruit Export Website

## 📌 Overview
The **Fruit Export Website** is a simple and responsive web project designed to showcase different fruits available for export. It provides a clean and user-friendly interface for displaying product details in an organized way.
(This is my second year mini-project)
---

## ✨ Features
- Responsive and modern homepage design  
- Display of fruit products with details  
- Simple and clean UI for better user experience  
- Easy navigation between sections  
- Lightweight and fast loading website  

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript
- Spreadsheet (for storing the data)

---

## 🌐 Live Website Access

You can directly view and use this website from the repository.

👉 Step:
- Open the repository on GitHub  
- Click on the file named `main.html` this is my main file from which you can access the whole website      

Now you can easily access the full website locally.

---

## 🚀 How to Run This Project
1. Download or clone the repository  
2. Open the project folder  
3. Double-click on `main.html`  
4. The website will run in your browser
